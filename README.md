# AB-testing

## Цели исследования:

1. Аналитическая обработка маркетинговых гипотез для определения наиболее перспективных направлений развития, используя методики фреймворков ICE и RICE. Особое внимание уделено параметру охвата (Reach) при оценке потенциального эффекта.

   
2.Комплексный анализ экспериментальных данных с последующим обоснованием одного из решений:
- Фиксация превосходства одной из тестовых групп
- Констатация отсутствия значимых различий
- Продление теста для сбора дополнительных данных

## Ключевые выводы по A/B-тесту:
После устранения аномальных наблюдений и статистической верификации данных зафиксировано устойчивое преимущество группы B по показателю конверсии (+15,5%±2,1%, p=0,008). Другие метрики (средний чек, выручка) не демонстрируют значимых расхождений.

## Используемые библиотеки
*pandas, numpy, matplotlib, seaborn, math, datetime, scipy*
